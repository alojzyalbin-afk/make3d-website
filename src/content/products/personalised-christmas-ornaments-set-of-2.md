A set of 2 personalised Christmas ornaments, each with a name in raised letters. You pick the shapes, the names and the colours. Printed to order in Dublin, ready to hang on the tree or anywhere else in the house: a window, a door, a wall, a shelf or a gift.

### The 3 shapes

Choose any combination of 2 of these 3 shapes.

- Paw - a paw print with snowflakes, made for a pet's name. 89 x 85 x 3 mm
- Bow - a Christmas bow with the name across it. 97 x 85 x 3 mm
- Jumper - a Christmas jumper with a reindeer and snowflakes, with the name on the front. 110 x 85 x 3 mm

### Details

- Set of 2 ornaments, 3D printed in PLA plastic
- 3 mm thick in total: the base is 2 mm and the raised top layer with the name is 1 mm
- Each ornament has a hanging loop with a hole
- Printed in two colours. The colours come from the plastic itself, with no paint
- 3D printed by me in Dublin, Ireland

### Colours

Any colour combination you like: one colour for the base and one for the raised top layer with the name. Both ornaments in the set are printed in the same colour combination. Please pick two colours that look clearly different, so the name is easy to read. If they are the same or too close, I will message you before printing so we can change one. Shades can differ a little from the photos and from your screen to real life.

### How to personalise

Write the shape and the name for each ornament in the order form, in the same order.

Example: Ornament 1: Paw - Lola. Ornament 2: Jumper - Marius.

Names are printed exactly as you type them, so please check the spelling. Short names look best. A longer name? Send me a message before you order.

### Great for

- Your own tree or any spot where a tree does not fit
- Pet lovers: a paw with the name of your dog or cat
- A couple, a pair of friends or two siblings, one ornament each
- Secret Santa and stocking fillers
- Teacher and colleague gifts

### Care

PLA plastic softens in heat, so keep the ornaments away from radiators, candles and hot bulbs. Wipe with a dry or damp cloth. Not a toy: keep them away from young children.
